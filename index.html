Four Shapes

A puzzle game with one undo.

Each board is a grid. Shapes are spread across it, and there is a row of empty docks along the top. Drag a shape and it moves along the line you draw, picking up every shape of its own kind that it passes. Put it in the dock that matches it. Clear the board and the level is done.

One rule makes it hard: inside a row, you can only go one way. If you go left, that row stays left. And you get one undo — one for the whole level, not one for each mistake.

164 levels in four chapters. Every level has a lowest possible move count, and a solver found that line before the level shipped, so every level can be done. Finding it is the hard part.
